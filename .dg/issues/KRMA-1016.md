## Objective

Record the signed-app and hands-on evidence the 2026-10-14 review requires before a public v1 claim. This ticket does not implement the product fixes.

## Context

Local tests and an ad hoc `scripts/app-store-build.sh` pass are not Apple signing, TestFlight, a macOS 26 runtime pass, or a sandbox acceptance pass. The review host was macOS 27.2 with Xcode 27 beta. The deployment floor is macOS 26 on Apple Silicon.

Do not start the hands-on list until the must-fix children of KRMA-994 are `done`: KRMA-995, KRMA-996, KRMA-997, KRMA-998, KRMA-999, KRMA-1000, KRMA-1001. Retouch camera-scale inspection waits on KRMA-1003. A display capture waits on a recorded reopen decision in KRMA-952. Do not run `scripts/run-kromora-capture.sh` to "get a number" while that decision is won't-do.

Parent epic: KRMA-994. Human review stays required. An agent may prepare the evidence template and must not mark this done.

## Acceptance criteria

- [ ] A comment logs each item below with date, commit, OS, machine, and pass/fail, or with an explicit waiver via `dg decision`.
- [ ] On a 16 GB Apple Silicon Mac, scroll a library of thousands of edited photos and back under memory pressure. Memory plateaus and revisits hydrate. Use disposable data. Also note interrupted media and disk exhaustion if you can do that without a user library.
- [ ] Inspect supported retouch repairs at camera scale against the shipping gate. Do not treat the stress report as the sign-off.
- [ ] Run the signed sandboxed app on macOS 26: Library, Edit, Export, Quit, Relaunch, in a disposable profile. Include denied Photos access, bookmarks after relaunch, an external save destination, and cancellation.
- [ ] Replace a derived Look staged outside Pictures, under the real sandbox. Record whether a file-only panel grant plus sibling staging is denied.
- [ ] Visual and accessibility pass: rapid workspace and photo changes, crop, rotation, comparison, mask overlays, resize, full screen, mixed DPI, Reduce Motion, VoiceOver, and keyboard focus around sheets. Note stale pixels, layout jumps, focus loss, flashes, and transitions that delay input.
- [ ] If KRMA-952 reopens a latency budget, run one supervised capture series under `CLAUDE.md` (caffeinate, one capture at a time, no `--force` to dodge the unchanged-tree guard). If it stays won't-do, write that and do not capture.
- [ ] Produce an Apple-signed archive, App Store validation, and an internal TestFlight install. The submission worksheet's owner-provided URLs and account details are filled or explicitly still blocked on the owner. Record the candidate commit.
