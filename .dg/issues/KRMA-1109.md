## Objective

Add shared structural tests for every Look in this family, plus a guard that keeps trademarked names out.

## Context

Research and parameter table: docs/FILM_SIMULATION_LOOKS_RESEARCH.md (read first). These are best-guess approximations from public qualitative descriptions; there is no reference to verify against, so no acceptance criterion may require matching a camera, a reference photo, or the parameter table within a tolerance. Naming rule: no Fujifilm or film-stock trademarks in Look names, manifest, inspector text, test names, or code identifiers; use the original names from the research doc. Never derive from Fuji JPEG/RAW pairs. Calibrate by eye against the neutral RAW develop of Sony ARW and Apple DNG/HEIC files in the gitignored realworldtest/ folder (Apple/Sony JPEGs already have baked-in looks; secondary check only).

Build a synthetic chart (gray ramp, hue sweep at three luminances, skin-hue patches) generated in the test target, not committed, and render it through each cube in the serial Core Image lane (scripts/ci-tests.sh serial). There is no reference to verify against, so this is structural only; do not add golden images or tolerances against the research table, and do not run the display-bound capture harness.

## Acceptance criteria

- Per-Look checks: parses at 33^3, tone curve monotonic, neutral axis behaves as declared, no clipping on the chart, skin-hue patches within the skinGuard limit.
- Relative-ordering checks between Looks live in one table in the test target.
- A check fails if a Fujifilm or film-stock trademark appears in Look names, manifest entries, or inspector strings.
- Behavior asserted per Look is listed in docs/LOOKS.md.
