## Objective

Make the next App Store archive acceptable to App Store Connect.

The Mac App Store rejects `com.apple.security.files.removable-media.read-only` as unsupported on macOS. Camera-card import already keeps an unreadable volume visible and recovers through an Open-panel grant, so the entitlement is not what makes that path work. The entitlement plist, the strict checker, the Xcode invariant test, and the App Store docs still declare it.

Organizer re-signs the app with Apple Distribution at upload and leaves the SwiftPM resource bundle on the development certificate. App Store Connect rejects that archive with ITMS-90284. `scripts/app-store-build.sh archive` must sign each resource bundle with the Apple Distribution certificate for the resolved team. `CURRENT_PROJECT_VERSION` must move from 1 to 2 so the corrected archive does not reuse an uploaded build.

This is release-readiness work under KRMA-1051. KRMA-1066, the TestFlight pilot, depends on it.

## Acceptance criteria

- [ ] The production entitlement set omits `com.apple.security.files.removable-media.read-only`. `Kromora/Kromora.entitlements`, `scripts/check-sandbox-entitlements.py`, `XcodeProjectInvariantTests`, and the App Store docs agree.
- [ ] Mounted camera cards stay listed when the sandbox cannot read them, and import still recovers through the Open-panel grant.
- [ ] `scripts/app-store-build.sh archive` signs each resource bundle in the archive with the Apple Distribution certificate for `DEVELOPMENT_TEAM`, using the hash from the existing certificate lookup.
- [ ] `CURRENT_PROJECT_VERSION` is 2, and `docs/PACKAGING.md` keeps team inference and describes the ITMS-90284 signing step.

## Implementation notes

The removable-media key is a declaration change. `MountedMediaVolumeProvider.discoverMountedVolumes()` already sets `requiresAccessGrant` when a mount is not readable; only its comment still assumed the entitlement.

Archive signing must use the team and SHA-1 hash from `signing_identity_rows`. The certificate display name's parenthetical is not the team id.
