## Objective

The menu item that exports the current edit of each selected photo must not be named Export Originals.

## Context

`MenuCommands.swift` (around line 184) has `Button("Export Originals…")` calling `.exportSelected`. `AppViewModel` (around line 4080) treats that as a batch export of each photo's edit document. Untouched source bytes are a different operation: the original-plus-settings bundle.

Rename the edited-output command to "Export Selected Photos…". Leave the bundle command's name accurate. Update any test, help string, or doc that quotes "Export Originals" as the current menu title. KRMA-1015 covers the broader doc pass; fix the menu title and the assertions that would fail because of it here. Parent epic: KRMA-994.

## Acceptance criteria

- [ ] The menu title that runs selected-photo edited export is "Export Selected Photos…".
- [ ] The command still exports the selected photos' edits, not the raw file bytes.
- [ ] The original-plus-settings bundle keeps a name that says original, and its behavior is unchanged.
- [ ] Menu tests that look up the old title are updated. `swift build` is warning-free. `scripts/ci-tests.sh fast` exits 0.
