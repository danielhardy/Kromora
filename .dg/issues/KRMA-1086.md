Fix and verification (2026-10-22, uncommitted in the working tree). ExportCoordinator.sourceAccess passes nativeExtent .zero, so RenderScale.factor returned 1.0 (proxy not downscaled) and snapping/refinement bounds were skipped, giving a different automatic source offset than the editor/harness (declared extent). RenderPipeline.render no longer forwards a zero nativeExtent as retouchSourceSize/sourceSize (nil when undeclared). Tests (RetouchExportBoundaryTests): testAutomaticHealSourceDoesNotDependOnDeclaredNativeExtent and testExportPixelsDoNotDependOnDeclaredNativeExtent; both fail on the original code (export differs by 2514 pixels, max 15) and pass with the fix.
