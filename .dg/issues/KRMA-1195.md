## Objective
Make export naming fit the number of photos: a single-photo export should allow the user to directly rename the output, while multiple-photo export should offer appropriate batch naming. Avoid retaining a source RAW extension in the resulting JPEG name.

## Context
The user reports naming controls need work and specifically wants to rename a single export. The supplied text after “rename” appears to contain incidental typing; no particular filename is required. The selection-aware workflow currently constructs `ExportFormatAccessoryView` with `batchNaming` even for one item and then asks for a folder. `ExportFilenamePolicy.baseName` appends Look/prefix/suffix to its supplied source string, and output adds the selected format extension. Trace the actual source-name inputs: if `DSC001.ARW` reaches that policy unchanged, an output can become `DSC001.ARW.jpg`; confirm the affected paths rather than assuming all source names include an extension.

## Acceptance criteria
- For one selected photo, provide a clear editable output name and use the user's chosen name for the exported file. Preserve the selected output format's correct extension, allow sensible names containing dots, and handle invalid or empty names and collisions predictably without silent overwrites.
- For multiple photos, retain or improve clear batch naming controls and an accurate example; each output gets a distinct predictable name under collisions. Switching between single and multiple selections presents controls appropriate to the selection and does not unintentionally reuse a one-off name as a batch rule.
- Strip the actual source file extension when deriving the default output base name: e.g. `DSC001.ARW` exported to JPEG defaults to `DSC001.jpg`, not `DSC001.ARW.jpg`. Preserve legitimate internal dots, Look naming and prefix/suffix behavior, and cover RAW and standard image sources. Do not strip arbitrary user-entered name components as if they were source extensions.
- Verify the name shown in setup matches the file actually produced for single and batch exports, including changed formats, duplicate names, package-backed assets and destination selection. Preserve safe filename handling and existing persisted naming preferences where applicable.
- Add focused filename-policy and coordinator/workflow tests, and follow CLAUDE.md testing guidance for shared models and AppKit/UI changes.
