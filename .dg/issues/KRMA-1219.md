## Failed behavior

`PreviewAdmissionCoordinator.scheduleAdjacentPreviewPrefetch` enqueues speculative neighbor `makeCIImage` requests on `self.engine`, which is also the visible preview engine. A RAW neighbor cache miss can run `CIRAWFilter` development and synchronous RGBAh materialization on that actor, delaying a visible preview. Current held-work tests cover export, edited thumbnails, and idle warming, but not this production prefetch path. `docs/TESTING.md` omits the remaining prefetch contention.

## Expected outcome

Speculative adjacent-photo prefetch does not occupy the visible preview engine actor. Preserve cancellation and source/revision fencing, semantic-mask behavior, and preview pixels. Document any duplicate decode, cache, or GPU-memory cost caused by separate engine ownership.

## Acceptance criteria

- Route adjacent prefetch away from the visible preview actor, or use a safe completed-value boundary that prevents RAW development/readback from blocking it.
- Add deterministic tests through the production adjacent-prefetch scheduler path that hold prefetch work and prove a visible preview completes with pixel parity; cover RAW cache-miss development where feasible, cancellation, and stale source/revision rejection.
- Update `docs/TESTING.md` with prefetch ownership and remaining contention/cost.
- Run the affected preview-admission and render-isolation tests plus `scripts/ci-tests.sh serial`.
