## Objective

Give a release tester an accurate, executable checklist for the current packaged app.

## Context and reproduction

The October 19 review found that APP_STORE_ACCEPTANCE still describes a one-photo Save panel and a single-file collision contract. Current ordinary export uses a setup step and folder destination for one or many photos, with numeric collision suffixes. The checklist also says PhotosPicker import never requests broad Photos access; the current original-resource provider explicitly requests PhotoKit read/write authorization when undetermined. Entitlement-count wording is owned by KRMA-1054.

Update current-authority instructions, not historical review evidence. Distinguish ordinary edited export from Edit in External Editor, derived Look replacement, original+settings bundles, and optional Photos delivery; their overwrite/grant semantics differ.

Source review: .context/2026-10-19-release-readiness-review.md (reviewed bb01e0c374fb; re-read current code because subsequent work may have landed).
