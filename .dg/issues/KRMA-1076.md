## Objective

Explain or remove the bounded retouch-pixel difference between the signed packaged app's full-resolution
PNG export and the same source revision's window-independent qualification harness. Establish whether
it is an expected precision/build effect or an actual source-selection/render inconsistency.

## Context

During KRMA-1063, ad hoc Release candidate `116f14fddaa4` opened the disposable `Retouch Review
Library` and exported `01-sky-dust-auto-heal.png` through File > Export, PNG, 95% quality (ignored for
PNG), metadata preserved, GPS excluded, sharpening None, full size. The output is
`.build/krma1063-evidence/ui-exports/01-sky-dust-auto-heal.png.png`, 8064 × 6048.

The Debug-linked KromoraKit harness at the same product source had already exported that package's
saved one-spot automatic-source Heal document to `exports/01-sky-dust-auto-heal.png`. Both outputs
decode in a common sRGB RGBA CGContext. Exactly 2,023 of 48,771,072 pixels differ, all within inclusive
bounds x=4646–4707, y=756–815 around the repair. Maximum RGB channel delta is 2/255. Every other
pixel is equal. Native crop mean absolute RGB delta is 0.004951/255; full-frame mean is 0.00002437/255.
No visible failure, source-picker failure, or root cause has been established.

Local reproducible evidence is under `.build/krma1063-evidence/`: `run.swift`, `compare-ui.swift`,
`ui-export-check.json`, `ui-export-difference.json`, `results-final.json`, the two output PNGs,
and the disposable package. Fixtures originate in the licensed `realworldtest/IMG_0878.DNG`; controlled
dust was added to a native neutral develop. Private images must remain out of Git/uploads. The normal
personal library has already been restored; do not modify it while investigating.

Relevant unisolated differences: the harness links a Debug build and calls `RenderEngine.render`
for in-memory encoded data, while the packaged Release app passes explicit asset identity/export
options through ExportCoordinator and `RenderEngine.encode` to a staging file. The source-selection,
cache, build optimization and encoding differences are hypotheses, not findings.
