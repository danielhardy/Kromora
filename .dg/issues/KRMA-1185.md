## Objective

Determine whether global Saturation can preserve more saturated highlight detail at delivery without harming hue, brightness, or the unified control's behavior.

## Context

KRMA-1179's RAW characterization found that Saturation +50/+100 can put 0.33–0.67 of the selected saturated-region channels on output rails in several files. The same RGB stage serves RAW and standard images, so assess both source types. Evidence and limits are in `docs/RAW_PIPELINE_INSPECTION.md` under the KRMA-1179 section.

## Acceptance criteria

- [ ] Characterize the current Saturation range on representative RAW and standard images, with matched brightness and a fixed output transform; report channel rail counts, hue shift, and visible highlight color/texture, with Looks off and representative Looks on.
- [ ] Distinguish output gamut or tone-curve clipping from sensor clipping, and explain whether any proposed change preserves the existing control's intent.
- [ ] Record a recommendation and evidence in `docs/RAW_PIPELINE_INSPECTION.md` or a focused experiment note. Make no product behavior change unless the comparison demonstrates a repeatable improvement across both source types.

## Implementation notes

Keep the unified Color control and stored edit format. Use generated or local fixtures; record decoder and output transforms. Relevant code and tests include `Sources/KromoraKit/Models/RenderPipeline.swift`, `Sources/KromoraKit/Models/ColorAdjustments.swift`, and `Tests/KromoraKitTests/RAWColorHeadroomBenchmark.swift`.
