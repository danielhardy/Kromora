## Objective

Identify a reproducible source-selection/blending failure and provide larger generated quality fixtures for a bounded automatic-Heal fix.

## Context and reproduction

The current serial quality suite reports dust/speck Clone 10/12, Heal 10/12, auto Heal 11/12; hair/fibre Clone 2/6, Heal 2/6, auto Heal 0/6. The shipping floor for automatic hair is zero. All six backgrounds are generated 96x72 fixtures. This is an observed synthetic quality gap, not a measured real-camera failure rate. KRMA-1003/1004 fixed the separation of shipping/stress gates and brush-boundary blending; do not reopen those completed changes.

Trace RetouchSourcePicker's neutral analysis proxy and automatic source offsets into RetouchRenderer. Compare against the same manual candidate on known repairable rows to separate a bad source choice from a blending/scale problem. This ticket prepares concrete evidence for KRMA-1062; real-photo visual acceptance is KRMA-1063.

Source review: .context/2026-10-19-release-readiness-review.md (reviewed bb01e0c374fb; re-read current code because subsequent work may have landed).
