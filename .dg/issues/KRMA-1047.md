## Objective

Ensure the Share sheet's built-in Copy action is replaced by Kromora's image-byte copy service
when macOS uses a non-English language.

## Context

`SharePickerDelegate.sharingServicePicker` currently identifies the system Copy action with the
literal title `Copy`. When AppKit localizes that service title, the match fails and the implementation
appends its own English Copy service. The localized native Copy remains available and can still place
a temporary file representation on the pasteboard, which may stop working after Share cleanup.

## Acceptance criteria

- [ ] Identify and replace the native Copy action without relying only on the English title, while
      preserving other proposed sharing services.
- [ ] The custom action uses the native localized Copy label and no broken duplicate Copy action is
      shown.
- [ ] A deterministic test supplies a localized proposed title (for example, `Copier`) and proves
      the single Copy action writes decodable `public.jpeg` bytes to the pasteboard.
- [ ] `swift build` and focused Share workflow tests pass.

## Implementation notes

Keep the solution within the existing AppKit sharing-service boundary. Avoid private AppKit APIs.
