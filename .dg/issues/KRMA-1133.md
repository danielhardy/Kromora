## Objective

Honor HLG encoding metadata in generated Look cubes

## Context

`Tests/KromoraKitTests/SlideLookGenerator.swift` can emit cubes stamped with
`KROMORA_ENCODING: hlg`, but the application parser and renderer currently use only the
`KROMORA_AUTHORING_SPACE` stamp. `CubeLUT` interprets table values through the tagged `WorkingSpace`
color space, so an HLG-authored table can be silently treated as an sRGB-transfer P3 table. The
active Clean Slide asset uses the supported `sRGBTransfer` encoding; this follow-up covers future
HLG-authored Looks.

## Acceptance criteria

- [ ] Define the runtime contract for `KROMORA_ENCODING` and ensure an HLG-authored cube is either
  interpreted with its declared encoding or rejected before it can render with the wrong transfer
  function.
- [ ] Add a non-neutral generated HLG chart test through the `CubeLUT` / `RenderPipeline` path that
  verifies the declared encoding is honored; keep the Clean Slide P3/sRGB-transfer behavior unchanged.
- [ ] Document which Look encodings are supported for authoring and rendering.

## Implementation notes

Keep the default P3/sRGB-transfer Look path unchanged. Coordinate with the HDR/EDR scope in
KRMA-1128 if supporting HLG requires an app-wide rendering or delivery decision.

### Comment — claude @ 2026-10-26T19:11:19.676Z

Contract: KROMORA_ENCODING is validated at parse time in Sources/KromoraKit/Models/CubeLUT.swift. sRGBTransfer (or no header) is the only supported encoding; hlg or any other value throws LUTError.unsupported, so an HLG cube can never render with the sRGB transfer. Added SlideLookGeneratorTests.testHLGEncodedCubeIsRejectedBeforeItCanRenderWithTheWrongTransfer; the existing header test now covers only sRGBTransfer, and the Clean Slide P3/sRGBTransfer path is unchanged (SlideLookGeneratorTests and CubeLUT affected set: 80 tests pass). Documented in docs/LOOKS.md under Supported encodings. Chose rejection over interpretation: HLG rendering needs the HDR/EDR decision in KRMA-1128, so there is no non-neutral HLG render-path test. Not committed.
