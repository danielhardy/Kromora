## Objective

Show a photo's GPS location at a glance in the Info panel.

## Context

`ImageMetadata` reads embedded GPS coordinates and exposes a Location section in the Info inspector.
That section currently contains only a formatted Coordinates row. Replace the row-only presentation
with a compact map preview and a clear latitude/longitude readout so the photographer can orient
themselves without leaving the editor.

Precise coordinates are intentionally not copied into the library index; only a coarse cell is
stored for filtering. Keep the map driven by the currently loaded photo's valid GPS metadata, with no
reverse geocoding or access to the user's current location. MapKit may need network access to load
map imagery; the card should still show its pin and coordinates when imagery is unavailable.

## Acceptance criteria

- [ ] When the Location section is expanded and the photo has valid GPS coordinates, show a compact
      MapKit preview centered on that location with one pin at the exact coordinate.
- [ ] Show latitude and longitude directly beneath the map, with N/S and E/W hemispheres and useful
      precision. Render both values in a monospaced font and keep them selectable.
- [ ] Do not request Core Location permission, show the user's location, or reverse-geocode a place
      name. The pin and coordinates come only from the loaded photo's embedded GPS metadata.
- [ ] Missing or invalid GPS coordinates show no map or location card, matching the inspector's
      existing behavior for absent metadata; unavailable map imagery does not hide the pin or values.
- [ ] Keep exact coordinates out of persistent library indexes and coarse location facets.
- [ ] Add focused coverage for valid coordinates in each hemisphere, invalid/missing coordinates,
      and the Info panel's map and monospaced coordinate presentation.

## Implementation notes

The metadata reader is `Sources/KromoraKit/Models/ImageMetadata.swift`; the Location disclosure is
rendered in `Sources/KromoraKit/Views/InfoInspectorView.swift`. Provide validated numeric GPS values
for map positioning rather than parsing the formatted display string. Keep the preview compact and
use Apple frameworks only.
