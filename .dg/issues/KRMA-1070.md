## Objective

Write Kromora editor attribution and version to image exports

## Context

Kromora's Image I/O export path preserves selected source TIFF and EXIF dictionaries. The TIFF
`Software` field is currently copied from the source unchanged, so an edited export does not identify
Kromora as the software that produced it. TIFF defines `Software` (tag 305) for the name and version
of the software used to create the image; XMP's `xmp:CreatorTool` is the corresponding standard
application/tool attribution. These fields should identify the editor without claiming the
photographer's authorship. Use the app bundle's `CFBundleShortVersionString` and `CFBundleVersion`
so the attribution follows each release.

Kromora already has explicit preserve/strip metadata behavior and keeps GPS inclusion opt-in. The
new attribution must follow that policy: include it with preserved metadata, but do not add it to a
metadata-stripped export. Keep existing capture metadata behavior intact.

References: [TIFF 6.0 Software tag](https://www.itu.int/itudoc/itu-t/com16/tiff-fx/docs/tiff6.pdf),
[Adobe XMP Basic namespace](https://developer.adobe.com/xmp/docs/xmp-namespaces/xmp/).

## Acceptance criteria

- [ ] Metadata-preserving exports set TIFF `Software` (tag 305) to identify Kromora and include the
      current marketing version and build number from the app bundle; replace any source `Software`
      value because Kromora produced the rendered output.
- [ ] Where the output format supports XMP, set `xmp:CreatorTool` to the same Kromora/version/build
      identity. Do not write a photographer/creator credit on the user's behalf.
- [ ] TIFF, JPEG, PNG, and HEIF exports carry the attribution in the standard field(s) supported by
      each format, while unrelated preserved camera/EXIF metadata and the existing GPS opt-in remain
      unchanged.
- [ ] Metadata-stripped exports remain free of embedded metadata, including Kromora attribution.
- [ ] Focused tests read metadata back from encoded exports to verify the release-derived attribution
      and the preserve/strip behavior across supported formats.

## Implementation notes

The app version and build are declared in `App/Info.plist` and surfaced to packaged builds through
the bundle. Export metadata is assembled in `Sources/KromoraKit/Models/RenderEngine.swift`; focused
coverage belongs with `Tests/KromoraKitTests/` export/render tests. Preserve current handling of
orientation, resized pixel dimensions, camera metadata, and location consent.
