## Acceptance criteria

- [ ] Record candidate commit, app signing type, OS, machine, source dimensions, and fixture identifiers that can be resolved locally without publishing private photos.
- [ ] Review soft dust, hard specks, and hair/fibre over sky/cloud edges, textured foliage/water/brick, and skin-like detail using appropriate available representative crops; record omissions explicitly.
- [ ] Inspect at 100% source scale: remaining defect, halo/seam, blur/texture loss, duplicated structure, and source-patch contamination. Compare manual Heal, automatic source Heal, and Clone where relevant.
- [ ] Export and reopen representative full-resolution results; repairs, masks, and source offsets agree with the settled preview and persist after app relaunch.
- [ ] Record each case as Pass/Fail/Not run with local evidence references; file specific reproducible defects rather than claiming all photos behave like a synthetic pass rate.
- [ ] Link the evidence into KRMA-1016 and RETOUCH.md with scope/limitations; retain human review until a reviewer has assessed the actual pixels.
