## Objective

Stream the full-size rendered companion directly to the bundle staging directory so export does not retain the encoded TIFF and another complete copy during validation.

## Context

`Sources/KromoraKit/ViewModels/ExportWorkflowCoordinator.swift` calls `ExportCoordinator.renderEncodedData` for a full-size 16-bit TIFF. `OriginalSettingsBundle.create` retains the encoded `Data` while `OriginalSettingsBundle.verify` reads the finished companion into another `Data` for its checksum. High-resolution RAW exports can use hundreds of megabytes or more, making this peak memory unnecessarily high. The existing `ExportCoordinator` uses `RenderEngining.encode(_:to:)` to stream encoded bytes to a staging file.

## Acceptance criteria

- [ ] Keep the companion full-size, 16-bit TIFF with the canvas target ICC profile and preserve original bytes.
- [ ] Stream companion encoding, bundle writing, and checksum verification without materializing two full encoded TIFF copies in memory.
- [ ] Preserve atomic bundle publication and remove partial output after cancellation or failure.
- [ ] Add deterministic coverage for streamed companion integrity and cancellation/failure cleanup.
- [ ] Run `scripts/ci-tests.sh fast` and `scripts/ci-tests.sh serial`.

Relevant files: `Sources/KromoraKit/Models/OriginalSettingsBundle.swift`, `Sources/KromoraKit/ViewModels/ExportCoordinator.swift`, `Sources/KromoraKit/ViewModels/ExportWorkflowCoordinator.swift`, and `Tests/KromoraKitTests/OriginalSettingsBundleTests.swift`.
