## Objective

A missing or unloadable required image kernel must fail the render/export visibly instead of silently omitting a saved edit.

## Context

Source: audit `.context/audits/2026-11-03-code-quality-audit.md` (against `b7e46d5c`); probe source and outputs are in `.context/audits/evidence/2026-11-03/README.md`. Line numbers below are from that commit and may drift.

`CIKernelLibrary` (`Support/CIKernelLibrary.swift`) returns optional kernels, and several rendering helpers fall back to the input or current image when a required operation cannot be built, for example mask inversion/combination in `LocalMaskRenderer` (`Models/LocalMaskRenderer.swift:133`). Parity and resource-freshness tests guard the shipping bundle, but do not make runtime kernel or command failure impossible. A decorative overlay can degrade; a kernel needed to reproduce a saved local adjustment cannot yield a "successful" export without that adjustment. No damaged bundle was exercised.

## Acceptance criteria

- [ ] Required render capabilities are validated once, preserving the underlying load error.
- [ ] Pixel-producing document operations (local masks and adjustments) propagate an actionable render/export failure when their kernel is unavailable; optional presentation effects may still degrade.
- [ ] A failed GPU completion for an export surfaces as a failure and is not committed as a finished export; the document is preserved.
- [ ] No crash is used to report a recoverable rendering failure.
- [ ] Tests inject a missing/unloadable required kernel and a failed completion; existing neutral/no-op and unsupported-capability behavior is unchanged. Serial lane (`scripts/ci-tests.sh serial`) passes.

## Implementation notes

- Keep Core Image graph construction inside `RenderEngine` (CLAUDE.md). Classify each fallback site as required vs optional in the ticket before changing it.


### Comment — claude @ 2026-11-03T23:53:56.833Z

Implemented in commit 44d0b924. Fallback classification: every kernel in CIKernelLibrary.expectedKernelNames produces document pixels, so all are REQUIRED when their edit is non-identity (applyToneCurve, hslMixer, colorGrading, effectsVignette, effectsGrain, effectsMidtoneMask for clarity, localAnalyticMask/localInvertMask/localCombineMask, retouchPull/Push/ApplyCorrection/MembraneApply); none is currently a decorative optional effect. Mechanism: CIKernelLibraryStatus.bundled validates the bundle once and keeps the underlying load error; RenderKernelRequirements.names(for:) maps a document to needed kernels; RenderEngine.buildImage throws CIKernelLibraryError before building a graph, so render/encode/export fail (staging file removed, nothing committed, document untouched) and makeCIImage returns nil to the existing preview failure path. LocalMaskRenderer.inverted/combined now throw instead of returning the unmodified mask. Neutral documents need no kernels and are unchanged. Tests: Tests/KromoraKitTests/RenderKernelAvailabilityTests.swift (injected status on RenderEngine/LocalMaskRenderer). Gaps, stated plainly: (1) there is no injectable seam for a failed Metal command-buffer completion. Full-scale export never uses a command buffer (CIContext.createCGImage nil already throws ImageError.exportFailed and ExportStreamingTests covers staging cleanup); the preview/prefix commitAndWaitForCompletion failures already return nil and fall back, so no failed-completion test was added. (2) scripts/ci-tests.sh serial: 771/772 pass; the one failure, PreviewCutoverTests/testOrphanedSettledPreviewDoesNotBlockTheNextPhoto, fails identically on clean HEAD 75390eb5 (verified in a throwaway worktree, since removed), so it is pre-existing and unrelated (fake-engine preview scheduling).

### Verification blocker — export GPU completion failure

- Failed behavior: the acceptance criterion for an export GPU completion failure is not demonstrated. `RenderEngine.finalize` uses `CIContext.createCGImage` and does not observe or inject an export command-buffer completion result; the current failure tests cover missing kernels only.
- Required change: make export render completion failures observable and propagate them as an actionable failure before a finished export is committed. Partial staging output must be removed, and the durable edit document must remain unchanged.
- Verification: add deterministic injected failed-completion coverage asserting the export fails, no finished or staged file remains, and the document is unchanged; run `scripts/ci-tests.sh serial`.
