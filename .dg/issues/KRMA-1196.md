## Objective
Remove the parenthesized technical abbreviations from the export metadata checkbox labels, as requested: display “Preserve camera metadata” and “Include location metadata”.

## Context
`ExportFormatAccessoryView` currently labels the checkboxes “Preserve camera metadata (EXIF/TIFF)” and “Include location metadata (GPS)”. Existing tests locate the controls by these labels. The location checkbox is opt-in; its accessibility help explains the privacy consequence.

## Acceptance criteria
- The two export checkbox labels read “Preserve camera metadata” and “Include location metadata” without the parenthesized abbreviations; the layout and accessible names match the visible wording.
- Preserve the existing metadata behavior, default-off location setting and clear accessibility explanation of location sharing. Update focused tests that identify the labels and verify both controls still map to their existing settings.
- Follow CLAUDE.md targeted testing and serial-lane guidance for AppKit/UI changes.
