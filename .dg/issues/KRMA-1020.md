For an unloaded package selection with a scheduled library-state drain, persistUnloadedLibraryState builds full rating and flag updates from browsingAssets(forIDs:) index summaries. Back-to-back rating and flag actions can run before the first scheduled commit publishes its summary; the later flag update then carries the old rating and overwrites the in-flight rating. Expected outcome: culling updates merge with the newest queued or in-flight state so changing a second field never reverts the first. Acceptance criteria: (1) Add a deterministic scheduler-gated test with a three-photo package and page size two. Select all, queue a rating change, then queue a flag change before the first write completes; after flush, all photos retain both new values. (2) Preserve last-intent coalescing, write-failure reporting, and retry behavior. (3) Run swift build and scripts/ci-tests.sh fast successfully.
