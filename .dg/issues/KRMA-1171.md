## Objective

Bound the lifetime memory used by parsed embedded Looks as package assets are loaded.

## Context

`EditDocumentStore` bounds its document cache to 128 entries and the parsed-Look cache to 32 entries, but `StoredLookRegistry` retains a `CubeLUT` per loaded asset without eviction. Preview prefetch and batch export can load assets beyond those cache bounds; for assets with distinct embedded Looks, their parsed table data remains strongly held for the lifetime of the store.

Relevant paths: `Sources/KromoraKit/Models/StoredLookRegistry.swift`, `Sources/KromoraKit/Models/EditDocumentStore.swift`, `Sources/KromoraKit/ViewModels/PreviewAdmissionCoordinator.swift`, `Sources/KromoraKit/ViewModels/ExportCoordinator.swift`.

## Acceptance criteria

- [ ] Retained parsed embedded Look tables are bounded to a documented working set, rather than growing with every asset ever loaded.
- [ ] Eviction does not change exact-hash resolution: a revisited asset can reload its Look from its package reference and reproduce the same pixels.
- [ ] Tests load more unique embedded Looks than the configured bound, assert bounded retained state, and verify resolution after revisiting an evicted asset.

## Implementation notes

Preserve synchronous resolution for the active and imminent thumbnail/export work, and never substitute a different Look to reduce memory use.
