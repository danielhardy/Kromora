## Objective

Reduce composition-root risk by documenting the concrete lifecycle contract and closing meaningful cross-feature test gaps before considering another extraction.

## Context and reproduction

The review noted a 5,051-line AppViewModel and many focused coordinators. File size alone is not a defect, and completed decomposition work KRMA-460/529 should not be reopened. Remaining risk is root sequencing among source preparation/adoption, dirty persistence, history operations, preview publication, accepted export jobs, and lease release.

This is a bounded ownership/behavior audit. Use existing SourceSessionCoordinatorTests, StoredEditAdoptionTests, EditPersistenceIntegrationTests, TerminationGuardTests, ApplicationShellCoordinatorTests, and EditHistoryCoordinatorTests first. Add tests only for missing observable behavior, using controlled completion gates rather than large numbers of Task.yield polls.
