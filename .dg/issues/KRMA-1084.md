## Objective

Add action-level tests for the Library and filmstrip photo context menus so every routed action is verified against the intended context photo or resolved selection.

## Context

KRMA-1080 adds context-menu routing for Open in Edit, Copy Image, Copy Edit Settings, Paste Edit Settings, Export, and Share. Current focused tests cover target resolution, availability, flags/ratings, delete confirmation, and virtual copies, but do not assert the full action-routing behavior for those six paths.

## Acceptance criteria

- [ ] Copy Image is shown to copy developed output for the context photo or selected photos through the existing export workflow.
- [ ] Copy Edit Settings reads the photo under the pointer, including when it is not the active edit photo.
- [ ] Positive Paste Edit Settings coverage verifies the intended single or multi-photo targets and durable edit behavior.
- [ ] Open in Edit switches to the context photo only when selected as an action.
- [ ] Export and Share receive the resolved context target or selection without widening to unrelated library photos.
- [ ] Tests use isolated package fixtures and do not write to the user's general pasteboard or open system share UI.

## Implementation notes

Add focused tests in `Tests/KromoraKitTests/LibraryContextMenuTests.swift`, using the existing workflow seams and temporary package fixtures.
