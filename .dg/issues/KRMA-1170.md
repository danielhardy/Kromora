## Objective

Carry the source revision's verified embedded Look into a virtual copy so the copy remains reproducible from the package alone.

## Context

`EditHistoryCoordinator.createVirtualCopy` saves the copied document under the destination asset. In `EditDocumentStore.sourceLookBytes`, that new asset has no current revision to inherit from, so the save falls back to the in-memory external Look bytes. If the source Look exists only as the source asset's embedded reference and the external file is missing, the copy keeps the `LUTID` but receives no Look reference.

Relevant paths: `Sources/KromoraKit/ViewModels/EditHistoryCoordinator.swift`, `Sources/KromoraKit/Models/EditDocumentStore.swift`, `Sources/KromoraKit/ViewModels/AppViewModel.swift`.

## Acceptance criteria

- [ ] Creating a virtual copy from an asset with an embedded Look preserves the verified source Look bytes in the copy revision when the external Look file is unavailable.
- [ ] A fresh store resolves and exports the copy using only its package reference; rendered pixels match the source revision.
- [ ] A copy with an unresolvable source Look retains the reference and does not silently substitute another Look.

## Implementation notes

Keep the copied edit independent from subsequent source edits, and keep Core Image graph construction inside `RenderEngine`.
