## Objective
When a user imports or opens a photo into an existing library, open the requested photo rather than an unrelated first photo in the library.

## Confirmed code path
The user reports importing a photo takes them to the first library photo instead of the photo opened. Static inspection confirms the file-URL path can do this: `AppViewModel.openImages` reloads the portable collection on success and unconditionally calls `openPortableAsset` on `collection.items.first`. That is the first item in the displayed library page, not necessarily an item in the import result. This has not been reproduced in the running app as part of ticket creation. `PackageSourceImportCoordinator.openFirstAsset` already chooses an imported or duplicate asset ID for other source workflows; investigate shared semantics and asynchronous selection rather than assuming all entry points fail identically.

## Acceptance criteria
- Reproduce with a nonempty library where the requested file sorts after an existing photo, and add a regression test proving a successful single-file import opens and selects that requested asset, with the correct preview and library selection even when it is outside the first page or the current sort differs.
- Opening a duplicate selects its existing library asset. Define and test deterministic behavior for multiple requested files, mixed new/duplicate results, and partial or total failure; never open an unrelated first library item merely because no requested asset was imported.
- Audit file-open, drop, folder, removable-media and Photos entry points for the same issue and preserve their intended selection semantics. Ensure delayed refresh or a superseded import cannot overwrite a more recent user selection or open the wrong asset.
- Preserve import outcomes, package membership, filtering/pagination and existing edit state; avoid using display names or transient row positions as identity. Add focused tests at the app/coordinator boundary covering the relevant asynchronous behavior.
- Follow CLAUDE.md targeted tests and required fast or serial lanes for the code touched; report reproduction and verification evidence.
