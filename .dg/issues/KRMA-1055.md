## Objective

Make the UI smoke command complete and verify the current one-photo export workflow in an isolated test profile.

## Context and reproduction

Finding 4: smoke-macos-app.sh presses Command-S, waits for a window named Export, edits Save As:, and clicks Save. Current ExportWorkflowCoordinator.exportDialog routes one or many selected photos through ExportCoordinator.batchExportDialog: Export 1 Photo setup, then a folder chooser with Export Here. The old script cannot complete that route.

CI can also return success when the script exits 2 for an unavailable UI session. That must remain a visible deferral, never accepted as an executed release smoke. The existing script imports into the app's selected/default library, so unattended use against a developer's profile can alter their real library. Run the real UI check only in a confirmed disposable macOS profile/library; this ticket does not authorize using the user's current photo library.

Source review: .context/2026-10-19-release-readiness-review.md (reviewed bb01e0c374fb; re-read current code because subsequent work may have landed).
