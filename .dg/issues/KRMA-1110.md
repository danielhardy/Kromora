## Objective

Rename the existing starter categories into the film-look categories, put Monochrome last, make the Look inspector show them in that order with an accurate acknowledgement, and update docs/LOOKS.md.

## Decision (made 2026-10-26, do not reopen)

Rename the existing categories; do not keep them alongside the new ones. Category order is explicit and fixed:

1. Slide
2. Negative
3. Cine
4. Monochrome (last)

Mapping for the 13 existing starters (change `category` in the manifest only; ids, names and cube bytes stay the same):

| Existing Look | Old category | New category |
| --- | --- | --- |
| Warm Slide | Warm slide-inspired | Slide |
| Hard Light | High-contrast | Slide |
| Muted Film | Film-inspired | Negative |
| Honey Negative | Film-inspired | Negative |
| Evening Cinema | Cinematic | Cine |
| Ember & Cyan | Cinematic | Cine |
| Pastel Wash | Pastel | Cine |
| Bleached Daylight | Faded | Cine |
| Soft Mono, Silver Noir, Paper Grain, Blueprint Mono, Infrared Mono | Monochrome | Monochrome |

Pastel Wash and Bleached Daylight go to Cine because they share Cine Flat's low-contrast, low-saturation territory. Retired-Look removal is KRMA-1131; do not remove anything here.

Monochrome moves from first to last. Today `LUTLibrary.starterCategoryPrecedes` forces Monochrome first and sorts the rest alphabetically. Replace that with an explicit ordered list (Slide, Negative, Cine, Monochrome), so order does not depend on alphabet; a bundled category not in the list sorts alphabetically between Cine and Monochrome, so Monochrome always stays last. User-owned categories (imported and saved Looks) keep their current ordering after the bundled ones.

## Context

Research and parameter table: docs/FILM_SIMULATION_LOOKS_RESEARCH.md (read first). Naming rule: no Fujifilm or film-stock trademarks in Look names, manifest, inspector text, tests names, or code identifiers; use the original names from the research doc. Cubes are original assets generated from qualitative public descriptions; never derive from Fuji JPEG/RAW pairs. Starting values are to be tuned by eye, not treated as measurements.

LUTLibrary.starterCategoryPrecedes defines category order and the manifest acknowledgement text is shown in the Look inspector. Update the starter library table in docs/LOOKS.md (currently says 13 Looks) and keep the 'descriptive inspiration only, no official profiles' wording; do not name manufacturers in the UI.
