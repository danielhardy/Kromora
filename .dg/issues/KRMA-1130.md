## Objective

Document the deliberate sRGB pin on the mask inspection overlay so it is not mistaken for a missed Display P3 migration.

## Context

Created from KRMA-1114 counterpoint verification. `RenderEngine.makeMaskOverlayImage` encodes its CGImage with a hard-coded sRGB color space, while render and delivery use `WorkingSpace.current` (Display P3). That matches ADR-KRMA-1115: the overlay is a presentation-only coverage image and is never exported or delivered. The pin was not documented at the call site.

## Acceptance criteria

- [x] The makeMaskOverlayImage color-space site documents that the overlay is an sRGB inspection image, not a delivery, and cites ADR-KRMA-1115.
- [x] Decide whether the overlay stays sRGB or moves to WorkingSpace.current; a color-space behavior change requires separate ticket review and a matching test.
- [x] scripts/test-affected.sh covers the touched suites and passes.

## Implementation notes
