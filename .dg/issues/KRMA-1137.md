## Objective

Keep the process-wide brush-stroke digest memo bounded in retained sample data while preserving paint-tick reuse.

## Context

`Sources/KromoraKit/Models/BrushStrokeDigest.swift` stores up to four full `BrushStroke` values per UUID and caps the dictionary at 4096 UUIDs. `BrushStroke.samples` has no size limit, so the entry cap does not bound retained bytes; deleted or superseded strokes can keep sample buffers alive. When a new UUID crosses the cap, the implementation clears the entire memo, which can force a broad re-encode.

## Acceptance criteria

- [ ] Set and document a measured retained-memory bound that accounts for sample arrays, and release evicted stroke buffers promptly.
- [ ] Eviction preserves exact digest semantics: edited or reordered strokes never alias, encoding failures remain uncacheable, and unchanged recent strokes still reuse digests.
- [ ] Add focused tests for the retention limit, eviction, and correct digest results after eviction.
- [ ] Benchmark a brush recipe beyond the current UUID threshold and report repeated paint-tick latency, including whether memo eviction causes broad re-encoding.

## Implementation notes

Keep this session-only; do not change durable `EditDocument.editHash` encoding or persist randomized hash output.
