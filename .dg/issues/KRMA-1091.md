## Objective

Finish the parts of the Library/Edit photo handoff that KRMA-1073 left open: keep the Library grid visually fixed behind the editor, and slide the editor chrome away on return.

## Context

KRMA-1073 (commit 328a3fb1) animates the photo between its Library cell and the Edit canvas and was reviewed live. Remaining gaps, from that review:

- `ContentView.detailContent` unmounts `LibraryGridView` while Edit shows, so on entrance the grid cross-fades out over 0.2s instead of staying fixed behind the growing photo.
- On return the grid mounts while the system inspector retracts, so its columns re-pack for about 0.3s under the static photo (cells measured 213, 245, 204, then 224 pt). The return flight now waits for the settled cell frame, so the contraction itself is stable.
- Library scroll offset and filters are not preserved across Edit; this was not checked.
- The filmstrip and inspector disappear at once on return rather than sliding away.
- Reduce Motion was not exercised live for either direction.

An earlier comment on KRMA-1073 judged keeping the grid mounted too costly for performance; measure that cost with the deterministic lanes in docs/TESTING.md, not the display-bound capture.

## Acceptance criteria

- [ ] During the entrance flight, other visible grid cells keep their positions and sizes; no cross-fade-out or reflow.
- [ ] During return, the grid is laid out at its final column count before the photo contracts, with no visible re-pack.
- [ ] Library scroll offset, filters, sort, and selection survive an Edit round trip.
- [ ] Editor chrome slides away on return as the reverse of the entrance.
- [ ] Reduce Motion uses the non-spatial path in both directions, checked live.
- [ ] Focused coverage for the new state; live review on a disposable library (scripts/disposable-app.sh, docs/TESTING.md).

## Implementation notes

Relevant: Sources/KromoraKit/Views/ContentView.swift, LibraryGridView.swift, ViewModels/LibraryHandoffState.swift. The flight overlay and settle logic in LibraryHandoffState should stay; this ticket changes what is mounted beneath it.
