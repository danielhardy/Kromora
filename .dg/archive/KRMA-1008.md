## Objective

The output-sharpening control in the export accessory must apply to batch export the same way it applies to a single export.

## Context

`ExportFormatAccessoryView` exposes medium and strength. `performExportFromDialog` passes `formatPicker.outputSharpening` into `ExportOptions` (`Sources/KromoraKit/ViewModels/ExportCoordinator.swift`, around line 255). `startBatchExport` (around line 447) builds `ExportOptions` without `outputSharpening`, so the batch uses the default and the user's choice is discarded.

Do not change which document is exported (KRMA-995) or job lifetime (KRMA-1000). Only thread the accessory value through. Parent epic: KRMA-994. Review, UI inconsistencies.

## Acceptance criteria

- [ ] A batch export started from the accessory uses the selected medium and strength on every item.
- [ ] A test sets a non-default sharpening value and asserts the batch options match the single-export options built from the same accessory state.
- [ ] The default accessory selection keeps today's default batch behavior.
- [ ] `swift build` is warning-free. `scripts/ci-tests.sh fast` exits 0.
